# 🏃 RUN2EARN - Web Chạy Bộ Kiếm Tiền (1m = 100₫)

Ứng dụng web chạy bộ công nghệ cao mang phong cách **Cyberpunk Athletic**. 
Mỗi 1 mét chạy được cộng ngay **100 VNĐ** (kèm hệ số nhân giày x1.0 -> x3.0 và buff tăng lực).

## ⚡ Các Tính Năng Chính

* 💰 **Quy đổi tức thì 1m = 100₫**: Tự động tính tiền thưởng theo từng mét di chuyển, kèm hiệu ứng xu vàng bay và âm thanh arcade giòn tan.
* 🏃 **2 Chế độ chạy linh hoạt**:
  * **Mô Phỏng / Máy Chạy Bộ**: Thanh trượt tốc độ 1 - 25 km/h, các nút tốc độ nhanh (Đi bộ, Jogging, Chạy nhanh, Bứt tốc).
  * **GPS Thực Tế Ngoài Trời**: Định vị vệ tinh qua HTML5 Geolocation, đo quãng đường chính xác theo mét khi chạy ngoài đường.
* 🛣️ **Đường chạy 3D & Bản đồ GPS**:
  * Đường chạy phối cảnh 3D trên Canvas với runner đồng bộ nhịp độ.
  * Bản đồ đêm Leaflet.js quanh Hồ Hoàn Kiếm, Phố Đi Bộ Nguyễn Huệ, Biển Mỹ Khê Đà Nẵng.
* 👟 **Cửa hàng nâng cấp giày**: Mua giày bằng tiền chạy kiếm được để nâng hệ số nhận tiền lên tới 300₫ / mét.
* 💳 **Ví & Rút tiền ảo**: Mô phỏng rút tiền về MoMo, ZaloPay, Vietcombank, MB Bank, Techcombank với biên lai điện tử.
* 🔊 **Âm thanh & Voice Coach**: Phát âm thanh nhặt xu và giọng nói tiếng Việt động viên qua từng cột mốc.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Trực Tiếp

Ứng dụng chạy hoàn toàn bằng **HTML, CSS và JavaScript thuần** (không cần cài thư viện phức tạp).

### Cách 1: Mở trực tiếp
Nhấp đúp chuột vào file `index.html` để mở trên bất kỳ trình duyệt nào.

### Cách 2: Chạy qua Local Server
```bash
# Sử dụng Python có sẵn trên máy:
python3 -m http.server 3000
```
Sau đó truy cập: `http://localhost:3000`

## 🌐 Triển Khai Miễn Phí Lên GitHub Pages
1. Vào repository trên GitHub của bạn.
2. Chọn **Settings** -> **Pages**.
3. Tại mục **Branch**, chọn `main` (hoặc `master`) và thư mục `/(root)`.
4. Bấm **Save**. Sau 1-2 phút, bạn sẽ có đường link trực tiếp (vd: `https://<ten-tai-khoan>.github.io/<ten-repo>`) để mở trên điện thoại cầm đi chạy ngoài đường!
